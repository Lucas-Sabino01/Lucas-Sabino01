### 🚀 Projetos em Destaque

Aqui estão alguns dos projetos que eu já desenvolvi ou que estou desenvolvendo:

#### 1. TecnoTooling-ALFA (Sistema de Gestão de Armazém - WMS)

Sistema de gestão de armazém (WMS) para a indústria, focado em substituir processos manuais por uma solução web moderna. O desafio foi criar uma UX simples para o almoxarife (operações do dia-a-dia) e, ao mesmo tempo, fornecer dashboards e relatórios e insights para a gerência.

- **Backend:** Kotlin, Spring Boot (com Spring Security para JWT) e PostgreSQL.
    
- _Nesse projeto fui responsável pela parte do `Front-End`_
- **Frontend:** React, TypeScript, Vite, TanStack Query, Zod, react-hook-form e **shadcn/ui**.
    

#### 2. Day@Shop (Solução de Otimização para a Valmet)

Aplicação web de gerenciamento de projetos desenvolvida para otimizar o fluxo de trabalho e a comunicação interna da Valmet. O projeto inclui um cronograma interativo, rastreamento de progresso e notificações em tempo real.
